# Kalkulator Man-day Audit SIP (PWA)

Cara pakai:
1. Unggah SELURUH isi folder ini ke hosting HTTPS (Netlify Drop, GitHub Pages, Cloudflare Pages, atau server internal).
   Uji lokal: jalankan `python -m http.server 8000` di folder ini, buka http://localhost:8000
2. Buka alamatnya di Chrome/Edge (Android/Windows) lalu pilih "Instal aplikasi", atau Safari iOS: Bagikan > Tambah ke Layar Utama.
3. Kunjungan pertama (online) menyimpan semua file dan pustaka PDF/Word; selanjutnya aplikasi bisa dipakai offline.

Catatan: jika file diubah, naikkan nilai V di sw.js (mis. md-calc-v2) agar pembaruan terpasang.
